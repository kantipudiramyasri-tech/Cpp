C++ Object-Oriented Programming Programs

This repository contains a collection of C++ programs demonstrating important concepts of Object-Oriented Programming (OOP). These programs are designed for learning and practicing core C++ concepts through simple examples.

📚 Topics Covered

The repository includes programs on the following concepts:

1. Operator Overloading

- Unary operator overloading using a member function
- Binary operator overloading using a member function
- Unary operator overloading using a friend function
- Binary operator overloading using a friend function

2. Types of Inheritance

The following forms of inheritance are demonstrated:

- Single Inheritance
- Multiple Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance

3. Constructors and Destructors

- Order of execution of constructors in inheritance
- Order of execution of destructors in inheritance

The program demonstrates that the base class constructor executes before the derived class constructor, while destructors execute in the reverse order.

4. Objects, Pointers and "this" Pointer

Programs demonstrating:

- Object as a class member
- Pointer to a class
- "this" pointer
- Virtual base class

5. Virtual Functions

Demonstrates the use of virtual functions and runtime polymorphism using a base-class pointer.

6. Pure Virtual Functions and Abstract Classes

Demonstrates:

- Pure virtual functions
- Abstract classes
- Runtime polymorphism
- Calculating the area of different shapes

The shapes included are:

- Circle
- Rectangle
- Triangle

🛠️ Technologies Used

- Language: C++
- Concept: Object-Oriented Programming
- Compiler: Any standard C++ compiler
